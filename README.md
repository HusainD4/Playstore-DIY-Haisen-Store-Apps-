# 🚀 Playstore DIY – Haisen Store Apps

> Platform distribusi aplikasi digital berbasis web yang terinspirasi dari konsep modern app marketplace seperti Google Play Store.  
> Dibuat untuk mendukung developer dan user dalam satu ekosistem **Haisen Business Platform**.

---

## 🌟 Overview

**Playstore DIY – Haisen Store Apps** adalah platform marketplace aplikasi berbasis web yang memungkinkan:

- 🔍 Pengguna menjelajahi aplikasi populer  
- 📥 Menginstall aplikasi secara digital  
- 📚 Melihat riwayat unduhan (Library)  
- 👨‍💻 Developer mengupload dan mengelola aplikasi  
- 🛠 Admin memonitor dan mengontrol seluruh sistem  

Project ini dirancang dengan tampilan modern, clean UI, serta pengalaman pengguna yang responsif dan interaktif.
